# Web app vs mobile app for UK small businesses (17 Oct 2026)
Facts: PWAs install from browser, one codebase, no store review/fees; native apps get full device features, store presence, push on iOS works for home-screen web apps since iOS 16.4 (2023). Prices: App Starter £1,249 (web app), App Pro £3,499 (iOS+Android), UK simple native app £8k–£40k (Foresight, Fulminous).
